OpenStreetMap als Fundament

Community

Freiwillige erfassen Defis

Mapper weltweit tragen Defibrillatoren in OSM ein – mit Standort, Öffnungszeiten, Betreiber und mehr.

defi_data Repository

Gefilterte GeoJSON-Dateien

Das Repo OpenBracketsCH/defi_data stellt pro Kanton eine saubere GeoJSON-Datei bereit.

jsDelivr CDN

Schnelle Auslieferung

Alle Dateien sind via CDN weltweit verfügbar – CORS-sicher, gecacht, sofort ladbar.

GitHub Actions

Monatlich automatisiert

Am 1. jeden Monats werden neue Zahlen gezählt, gespeichert und via FTP deployed.

Vanilla HTML/JS/CSS

Kein Framework, kein Build-Prozess. Eine Datei öffnen = fertig.

GitHub Actions

Zwei Workflows: CH-Kantone (09:00) & Nachbarländer (10:00) — am 1. jeden Monats vollautomatisch.

🌐

jsDelivr CDN

GeoJSON-Dateien per CDN geladen – CORS-sicher, weltweit schnell, kein eigener Server nötig.
